# DistributedProj4

## Project structure

The project consists of an include folder with all of the header files, a src folder with most of the cpp files (apart from main.cpp which is in the main), the docker compose files (4 in total), dockerfile, main.cpp, and a README.md.

## How to run:
cd ./project4

make Build-Images

### To run test 1
make Run-Testcase1

### To run test 2
make Run-Testcase2

### To run test 3
make Run-Testcase3

### To run test 4
make Run-Testcase4

### To run test 5
make Run-Testcase5
